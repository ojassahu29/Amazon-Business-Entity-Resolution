# Agent Wiki

This is the navigation page for agents working in this repository. Read the page closest to your task. Source code and tests are authoritative; use this wiki to find the right evidence.

## Start here

- New to the task? Read [the challenge and its data](problem-and-data.md).
- Changing candidate retrieval or matching? Read [the pipeline](pipeline.md).
- Changing scoring or reporting? Read [evaluation and limits](evaluation.md).
- Looking for the right module? Use the [code map](code-map.md).
- Need setup, run, or test commands? Read [working in this repository](working-in-this-repo.md).

## Agent contract

[`AGENTS.md`](../AGENTS.md) contains required agent rules. Agents must check the wiki for every code change and update affected pages in the same change when documented facts change.

## Page maintenance

This wiki is written and maintained by agents. Keep each page short, link claims to the source files or official challenge statement, remove stale claims, and update this page when navigation changes. Do not copy a result from an old README and present it as a new run.
